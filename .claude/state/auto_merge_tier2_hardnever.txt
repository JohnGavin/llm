# The Tier 2 HARD-NEVER list, read by bin/auto_merge_sweep.sh via
# .claude/scripts/lib/merge_classify.sh. A Tier 2 PR whose diff touches ANY path
# matching ANY line (new path or, for a rename, the previous path) is never
# eligible: it stays owner-verb ("merge"), always.
#
# Format: POSIX extended regexes (grep -E), one per line, matched against the
# repo-relative path. '#' lines and blank lines are ignored. A file with zero
# regexes or one that does not compile makes the sweep answer INDETERMINATE.
#
# One rule is not a path and lives in merge_classify.sh (MC_LIST_FILE_RE): a PR
# that REMOVES a line from a term / allow / deny list file is hard-never too.
